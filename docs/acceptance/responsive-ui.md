## 1. 修复内容

| 问题 | 修复 |
|---|---|
| 无侧栏页面在桌面端被压缩到 220px | `AppShell` 仅在存在侧栏插槽时启用两列网格，否则主体全宽 |
| 560px 以下隐藏主导航 | 移动端改为第二行横向导航，保留资源、论坛、个人中心等入口 |
| 移动端资源分类纵向占用首屏 | 改为横向滚动标签 |
| 移动端论坛分类纵向占用首屏 | 改为横向滚动标签 |
| 移动端个人中心导航纵向占用首屏 | 改为横向滚动标签 |
| 注册页用户名提示与实际规则不一致 | 提示改为“3～32 位字母、数字、_ 或 -” |
