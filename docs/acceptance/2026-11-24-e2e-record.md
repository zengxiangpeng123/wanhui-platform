## 4. 验收过程中发现并修复的问题

| 问题 | 影响 | 修复 |
|---|---|---|
| Spring Security 7 默认 XOR 编码 CSRF token，前端发送原始 cookie 值导致所有写请求 403 | 收藏、发帖、评论、点赞、改资料全部失败 | SecurityConfig 改用 CsrfTokenRequestAttributeHandler（SPA 标准 Cookie→Header 模式） |
| 资源首页缺少收藏入口，收藏页提示"在首页点击收藏"但无按钮 | 资源收藏流程不可用 | 后端目录 DTO 增加 favorited 字段；前端 ResourceCard 增加收藏按钮并接入收藏/取消 API |
| 退出登录接口失败时错误未被捕获，产生未处理 rejection | 页面残留登录态或控制台报错 | auth.logout() 增加 catch，无论接口结果都清理本地会话 |
| Vitest 误收集 e2e/*.spec.ts | 单测失败 | vite.config.ts 的 test.exclude 排除 e2e、报告目录 |
| Vite 仅监听 localhost，Playwright 探测 127.0.0.1 超时 | E2E 启动失败 | server.host 显式设为 127.0.0.1 |
