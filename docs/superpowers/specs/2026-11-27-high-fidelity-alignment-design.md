## 1. 目标

将现有 Vue 3 前端从通用蓝紫界面调整为高保真原型的深绿色资源工作台风格，保证核心页面的布局、信息层级、色彩、圆角和交互反馈与视觉基线一致。

## 2. 非目标

- 不修改后端 API、数据库结构和权限模型。
- 不复制原型中的演示控制台、假数据和模拟认证。
- 不改变现有业务测试中可观察的行为和字段。
- 不新增 UI 框架、图标库或外部字体。

## 3. 视觉基线

- 品牌主色：`#176b5b`
- 品牌深色：`#115447`
- 正文标题：`#1b2522`
- 次要文字：`#68736e`
- 边框：`#dee5e0`
- 页面背景：浅绿灰
- 卡片：白底、细边框、低阴影、16px 左右圆角
- 顶栏：品牌标识 + 全局搜索 + 论坛入口 + 登录/用户菜单
- 首页：左侧资源工作台，右侧资源 Hero 与三列卡片网格
- 论坛：深绿色 Hero + 单列帖子卡片
- 登录/注册：左侧品牌说明 + 右侧表单卡片
- 个人中心与管理：浅色侧栏卡片 + 白色内容卡片

## 4. 实现策略

采用“设计令牌优先、页面逐层对齐”：

1. 全局建立语义化颜色、圆角、阴影和表单令牌，并覆盖 Element Plus 主色。
2. 重构顶部导航和 AppShell，建立页面统一容器与侧栏。
3. 重构资源首页、资源卡片和分类导航。
4. 重构论坛、帖子卡片和帖子详情。
5. 重构登录、注册、个人中心和管理页。
6. 使用 Playwright 校验桌面和移动端的关键视觉属性，并人工截图对照原型。

## 5. 保留约束

- 搜索、收藏、登录、发帖、评论、点赞、分页和权限流程保持可用。
- 移动端 375px 无横向溢出。
- 文字仍为纯文本转义输出，不引入 `v-html`。
- 表单错误、空状态、加载状态和危险操作提示保留。

## 6. 验收条件

- 主色、顶栏、首页、论坛、登录页的关键计算样式与高保真基线一致。
- 桌面端 1440px 首页为侧栏加资源网格，论坛为 Hero 加单列帖子。
- 移动端保持主导航、搜索入口和资源卡片可操作。
- 现有 Vitest、生产构建和 Playwright E2E 全部通过。
- 截图复核不存在明显布局压缩、遮挡或信息层级错误。
