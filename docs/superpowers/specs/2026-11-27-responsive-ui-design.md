# 万汇网响应式界面修复设计

| 项目 | 内容 |
|---|---|
| 日期 | 2026-11-27 |
| 范围 | 前端响应式布局与界面文案修复 |
| 状态 | 已确认 |

## 目标

修复无侧栏桌面页面被压缩、移动端主导航缺失、移动端侧栏占用首屏过多的问题，同时保持现有视觉语言和业务行为不变。

## 非目标

- 不重做整体视觉系统。
- 不修改后端 API、数据库结构或业务权限。
- 不新增 UI 组件库或依赖。

## 已选方案

采用最小响应式修复：

1. `AppShell` 只在存在侧栏插槽时使用两列网格，否则主内容全宽。
2. 移动端保留主导航，修改为第二行横向导航。
3. 资源分类、论坛分类和个人中心导航在移动端改为横向滚动标签。
4. 修正注册页用户名限制的提示文案。
5. 在桌面和 375px 移动端增加布局回归测试。

## 备选方案

- 全面视觉改版：成本高，超出当前问题范围。
- 仅修改断点宽度：无法解决桌面无侧栏页面被压缩和移动导航缺失。

## 验收条件

- 1440px 桌面端登录、注册、帖子详情、关于页面主体宽度正常。
- 375px 移动端可访问资源、论坛和个人中心导航。
- 移动端分类与个人中心导航为横向排列，主内容更早进入首屏。
- 页面无横向溢出，现有单元测试、E2E 和生产构建通过。
